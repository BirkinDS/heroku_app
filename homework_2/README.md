# Homework 2 
 
## Установка зависимостей

Из корня `heroku_app`:

```bash
pip install -r homework_2/requirements.txt
```

## Запуск всех пяти тестов

```bash
python homework_2/start_test/run_homework_2.py
```

В консоли перед каждым тестом будет выводиться номер и название задания.

## Где находится скачанный файл (задание 5)

Файл сохраняется в постоянную папку:

```text
homework_2/downloads/
```
Папка и файл остаются после завершения теста.
